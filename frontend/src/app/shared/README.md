# Shared

Reusable components used by more than one feature:

- `claims/`: claim building blocks (status chip, facts card, activity, table with an optional "In status for" column).
- `notifications/`: the claimants' toolbar bell (unread count, marks a notification read when opened).
- `query-state.ts`: loading bar or error banner for a query.
- `format-age.ts`: "15 minutes", "3 hours", "4 days" for time in status and oldest-waiting figures.
